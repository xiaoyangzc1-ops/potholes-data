# potholes-data

微信小程序《训练时间表—周次更新》仓库。

## 当前进度（V1已打通）

- ✅ 阶段一：方案设计
- ✅ 阶段二：基础项目（登录 / 首页 / 训练组）
- ✅ 阶段三：每周任务创建 + 手动填表
- ✅ 阶段四：汇总表 + 共同空闲 + 推荐训练时间
- ✅ 阶段五：发布最终训练时间 + 首页展示 + 历史周次
- ⏳ 阶段六/七：图片识别与聊天截图识别（预留下一版本）

## 如何运行

1. 使用微信开发者工具导入 `miniprogram/`
2. 体验流程：
   - 登录（学生/教练）
   - 创建/加入训练组
   - 教练创建本周任务
   - 学生填写本周空闲时间
   - 查看汇总与推荐
   - 教练发布最终训练时间
   - 查看历史周次

## 目录

- `miniprogram/pages/*` 页面实现
- `miniprogram/services/*` 本地 mock 数据读写服务
- `miniprogram/utils/*` 日期、时间与排班算法
- `tests/utils.schedule.test.js` 核心算法样例测试
