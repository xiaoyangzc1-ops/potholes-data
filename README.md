# potholes-data

微信小程序《训练时间表—周次更新》仓库。

## 当前进度（V1已打通，图片识别/聊天截图识别保留下一阶段）

- ✅ 阶段一：方案设计
- ✅ 阶段二：基础项目（登录 / 首页 / 训练组）
- ✅ 阶段三：每周任务创建 + 手动填表
- ✅ 阶段四：汇总表 + 共同空闲 + 推荐训练时间
- ✅ 阶段五：发布最终训练时间 + 首页展示 + 历史周次
- ⏳ 阶段六/七：图片识别与聊天截图识别（预留下一版本）

## 本地运行（微信开发者工具）

1. 下载并安装微信开发者工具（建议使用稳定版）。
2. 打开微信开发者工具，选择“导入项目”。
3. 项目目录选择仓库根目录（包含 `project.config.json`），工具会自动识别 `miniprogramRoot: miniprogram/`。
4. AppID 可选择：
   - 测试 AppID：`touristappid`（用于本地体验与调试）
   - 正式 AppID：替换 `project.config.json` 中的 `appid` 后再导入/编译
5. 点击“编译”运行小程序。
6. 体验流程：
   - 登录（学生/教练）
   - 创建/加入训练组
   - 教练创建本周任务
   - 学生填写本周空闲时间
   - 查看汇总与推荐
   - 教练发布最终训练时间
   - 查看历史周次

## 目录

- `miniprogram/pages/*` 页面实现
- `miniprogram/services/*` 本地 mock 数据读写服务
- `miniprogram/utils/*` 日期、时间与排班算法
- `tests/utils.schedule.test.js` 核心算法样例测试
